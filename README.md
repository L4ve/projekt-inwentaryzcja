Inventory API

REST API for managing inventory items.

The API is used by the React frontend to communicate with the MySQL database through an Express server.

Base URL:

http://localhost:4000

==================================================

1. TECHNOLOGIES

Frontend:
React

Backend:
Express.js

Database:
MySQL

==================================================

2. GETTING STARTED

Install dependencies:

npm install


Start the API:

node index.js


The server will start on:

http://localhost:4000

==================================================

3. AUTHENTICATION

Authentication is not required in the current version.

The API does not use API keys, tokens, or user accounts.

==================================================

4. DATA MODEL

The API works with inventory items.

Example item:

{
  "id": 1,
  "inventory_number": "INV-001",
  "manufacturer": "Dell",
  "model": "Latitude 5520"
}


1. id

Unique identifier generated by the database.

2. inventory_number

Inventory number assigned to the item.

3. manufacturer

Manufacturer of the item.

4. model

Model of the item.

==================================================

5. API REFERENCE

GET /api/items

Returns all items stored in the inventory.

REQUEST

GET /api/items


No parameters are required.

EXAMPLE

const response = await fetch('http://localhost:4000/api/items')
const items = await response.json()

console.log(items)


RESPONSE

Status: 200 OK

[
  {
    "id": 1,
    "inventory_number": "INV-001",
    "manufacturer": "Dell",
    "model": "Latitude 5520"
  },
  {
    "id": 2,
    "inventory_number": "INV-002",
    "manufacturer": "Lenovo",
    "model": "ThinkPad T14"
  }
]


ERROR

Status: 500 Internal Server Error

{
  "error": "Database error message"
}

GET /api/items/:id

Returns one item using its ID.

REQUEST

GET /api/items/1


The id in the URL specifies which item should be returned.

EXAMPLE

const response = await fetch('http://localhost:4000/api/items/1')
const item = await response.json()

console.log(item)


RESPONSE

Status: 200 OK

{
  "id": 1,
  "inventory_number": "INV-001",
  "manufacturer": "Dell",
  "model": "Latitude 5520"
}


ITEM NOT FOUND

If the item does not exist, the current implementation returns:

null


The response status is still 200 OK.

ERROR

Status: 500 Internal Server Error

{
  "error": "Database error message"
}

POST /api/items

Creates a new item in the inventory.

REQUEST

POST /api/items
Content-Type: application/json


Request body:

{
  "inventory_number": "INV-003",
  "manufacturer": "HP",
  "model": "ProBook 450"
}


The request contains:

inventory_number

Inventory number of the item.

manufacturer

Manufacturer of the item.

model

Model of the item.

EXAMPLE

const response = await fetch('http://localhost:4000/api/items', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    inventory_number: 'INV-003',
    manufacturer: 'HP',
    model: 'ProBook 450'
  })
})

const result = await response.json()

console.log(result)


RESPONSE

Status: 200 OK

The API returns the ID of the newly created item:

{
  "id": 3
}


ERROR

Status: 500 Internal Server Error

{
  "error": "Database error message"
}

==================================================

6. ERROR HANDLING

The API currently handles errors that occur during database operations.

When a database error occurs, the server returns:

500 Internal Server Error


with the following JSON:

{
  "error": "Database error message"
}


The current implementation does not provide separate handling for invalid input or missing items.

9. TUTORIAL

This example shows how to add an item and then retrieve it.

STEP 1 — START THE SERVER

Run:

node index.js


The API will be available at:

http://localhost:4000


STEP 2 — GET THE CURRENT INVENTORY

Send a GET request:

const response = await fetch('http://localhost:4000/api/items')
const items = await response.json()

console.log(items)


The API returns all items currently stored in the database.

STEP 3 — ADD A NEW ITEM

Send a POST request:

const response = await fetch('http://localhost:4000/api/items', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    inventory_number: 'INV-100',
    manufacturer: 'Lenovo',
    model: 'ThinkPad T14'
  })
})

const result = await response.json()

console.log(result)


The API returns the ID of the new item:

{
  "id": 100
}


STEP 4 — GET THE NEW ITEM

Use the returned ID:

const response = await fetch('http://localhost:4000/api/items/100')
const item = await response.json()

console.log(item)


The API returns:

{
  "id": 100,
  "inventory_number": "INV-100",
  "manufacturer": "Lenovo",
  "model": "ThinkPad T14"
}
